# Models and Frameworks

Other than Nielsen's Usability Heuristics, I found other interesting models that focus on the human
computer interactions.

The first one comes from Schrepp Hinderks and Thomas Chewski and it's called the User Experience
Questionnaire (UEQ). It measures the user experience in a scale that looks at the classical usability
aspects like efficiency but also aspects like originality and stimulation. It does so measuring 7
dimensions from attractiveness and perspicuity all the way to novelty.

As a proposal for "objective" means of measuring UX it works, but I think it still relies a lot on
what the user thinks they see from experiencing the context for a few minutes and such feedback
can be very unreliable for our user analysis. It's also very binary on the item result list, going
from clear to complex should require an amount of steps other than one.

We could consider it for early user analysis.
