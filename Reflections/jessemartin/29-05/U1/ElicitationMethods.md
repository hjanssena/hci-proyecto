In order to make our user persona (Lupita) we needed demographic, educational, behavioral and
lifestyle data that could help us get a better idea of who would be using our system.

Our best option was to do this reasearch online, using a methodology similar to what we had been doing
with these reflections and using AI to get scientific and academic articles and papers that already
did this reasearch for us.

First, we gathered the most relevant articles considering our context on Mérida. Then, we took certain
key elements that could apport something to our persona like salary, skillset, goals or limitations.
Once we did this for all elements required in a user persona, we would manually search any missing info
or link that could be faulty coming from Perplexity and added all gathered key points in a report that
we added on the repo in case we needed to look back at something.
