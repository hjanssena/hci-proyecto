Using the paper "Intelligent User Interfaces and Their Evaluation: A Systematic Mapping Study" by
the University of Maribor in Slovenia I arrived to the argument that (at least while talking about
HCI) the usability attribute is only a part of the whole UX.

Considering the ISO's definition of usability as "Extent to which a system can be used by specified users to achieve goals with effectiveness, efficiency, and satisfaction"
would imply that certain conditions and results are to be expected before and after using a certain
sistem, which is what UX evaluates mostly.

In our proyect we only focused on usability during the first unit because we considered that once our
sistem accomodated the basic needs of the user within the system, then we could monitor and measure
how are we doing in UX.
