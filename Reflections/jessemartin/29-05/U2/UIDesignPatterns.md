Although we didn't see UI design patterns in class, I found another IEEE Access document released in 2025 that details
this exact topic, the name of the paper is "Improving Perception of Usability Through User Interface Design Patterns
to Optimize Information Architecture for Cognitive Benefits and User Satisfaction in Massive Open Online Courses".

My claim through this article is that UI design patterns directly impact usability perception and user
cognitive load. In class we discussed how cognitive load is a thing that's hard to properly measure
or define when looking to improve usability, but in this study with 232 university participants
it was found that students using Coursera's platform performed with higher ratings compared to Udemy's.
The difference was that Coursera's UI followed navigation patterns, feedback mechanisms, and other
patterns whilst Udemy didn't.

In our project, this was very clear when our faulty initial UI caused longer typing times. This became
even more clear when we did the UX testing with FMAT's administratives.
