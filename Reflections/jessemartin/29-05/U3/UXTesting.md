To us, User Engagement was the least important attribute to incluide in the project. To figure it out,
first we analyzed the attribute's definition by the ISO 25010: "Degree to which a user interface presents functions and information in an inviting and motivating manner encouraging continued interaction."

By this definition, we first thought of adding metrics like "time looking at screen" or something like
"mouse holding rate". The problem is that, to measure metrics like engagement we couldn't be present
during testing or ask for a out-loud-thinking form of testing because these sort of activities would
greatly impact how much attention the user would actually put in the actions they are making.

If we were to test for this, we would've added a testing scenario that incluide waiting times or longer
reading, maybe for finding a specific course from a list. This would also impact the time we take from
the nice people we are testing on. Maybe if we took it as an integral sort of metric at the very end
it could be considered, but probably not.
